# Clinic Knowledge Base Documents Directory

This directory stores the official source documents for the fictional **NovaCare Medical Centre** clinic knowledge base.

## Intended Purpose
- In Phase 02, this folder houses the source-of-truth reference files:
  - `NovaCare_Medical_Centre_RAG_Knowledge_Base.pdf`: Human-readable knowledge document.
  - `NovaCare_RAG_Source_of_Truth.json`: Structured source of truth for doctor schedules, fees, and clinic policies.
- These files are ingested and chunked during the RAG indexing pipeline.

## Security & Privacy Guidelines
- **Fictional Data Only**: All documents here represent fictional demo data for software assessment purposes.
- **No Real PHI/PII**: Never place real patient records, personal medical data, or real clinic operational files in this folder.

# Operational & Maintenance Scripts

This directory is designated for operational utilities, data preprocessing, and ingestion scripts.

## Planned Utilities (Later Phases)
- `ingest_knowledge_base.py`: Parses PDF/JSON source documents, generates embeddings, and constructs the FAISS vector index (Phase 02).
- `evaluate_rag.py`: Evaluates retrieval accuracy and semantic grounding against benchmark question sets (Phase 02 / Phase 05).
- `setup_tunnel.py` or tunnel verification scripts: Manages Cloudflare Quick Tunnel exposure for local development webhook testing (Phase 04 / Phase 05).
